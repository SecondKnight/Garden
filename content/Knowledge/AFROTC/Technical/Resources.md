# Internet

- To connect devices that doesn't work with **Eduroam** or the guest portals on the **Guest Network**, you must register them. Since this seems to be an issue, I'll make a mini-guide on it. The steps are as follows:

1. Log onto [wireless.ohio.edu](https://vm-dc-cppm-pub.net.oit.ohio.edu/guest/mac_create.php).
2. Find your Device's MAC address. If you can't find it, then read this [article]([https://www.ohio.edu/oit/connect-with-confidence/find-mac-addres](https://help.ohio.edu/TDClient/30/Portal/KB/Article/108/Finding-your-MAC-Address-Game-consoles-TVs-smart-sticks-and-speakers)s). If that doesn't work, then shoot me an <a href="mailto:Zw497925@ohio.edu?subject=AFROTC:%20Wifi-Related%20">email.</a>
